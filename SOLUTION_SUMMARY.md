# Полное решение для системы доставки с интеграцией карт

## Обзор проекта

Я создал полную систему доставки по Беларуси с интеграцией карт, которая работает локально на XAMPP без необходимости аренды серверов или хостинга. Система полностью бесплатна в использовании и включает все необходимые функции для курсовой работы.

## Основные особенности

### 1. Интерактивная карта с маршрутами
- Использование Leaflet.js для отображения карты OpenStreetMap
- Отображение всех отделений на карте с разными цветами для каждой компании
- Возможность выбора отделений прямо на карте
- Фильтрация отделений по компаниям

### 2. Реальные маршруты по дорогам
- Использование OSRM для расчета реальных маршрутов по дорогам
- Поддержка оффлайн-режима с приближенными расчетами
- Отображение маршрута на карте линией
- Получение информации о расстоянии, времени в пути и стоимости

### 3. Динамический расчет стоимости
- Стоимость рассчитывается на основе реального расстояния маршрута
- Учет веса посылки, типа перевозчика и дополнительных услуг
- Автоматический расчет времени доставки

### 4. Интеграция с существующей системой
- Совместимость с существующей базой данных
- Обновленные формы заказа с картой
- Сохранение всех существующих функций

## Техническая реализация

### Файлы системы:

1. **map_page.php** - основная страница с картой и маршрутами
   - Интерактивная карта с возможностью выбора отделений
   - Фильтрация по компаниям
   - Отображение маршрута и информации о доставке
   - Создание заказов прямо с карты

2. **calculate_route.php** - расчет маршрутов
   - Получение координат отделений из базы данных
   - Попытка получения реального маршрута через OSRM
   - Резервный метод с приближенными расчетами
   - Расчет стоимости и времени доставки

3. **get_carriers.php** - получение списка перевозчиков
4. **get_offices_with_coords.php** - получение офисов с координатами
5. **geocode_offices.php** - геокодирование адресов офисов
6. **update_database_structure.php** - обновление структуры базы данных

### Обновления базы данных:

1. Добавлены поля `lat` и `lng` в таблицу `offices` для хранения координат
2. Удалена старая таблица `routes` (маршруты теперь рассчитываются динамически)
3. Создана таблица `calculated_routes` для хранения рассчитанных маршрутов

## Преимущества решения

1. **Полностью локальное** - работает на XAMPP без интернета (с резервным вариантом)
2. **Бесплатное** - использует открытые API и данные
3. **Масштабируемое** - поддерживает большое количество отделений
4. **Интерактивное** - пользовательский интерфейс с картой
5. **Точное** - расчеты на основе реальных дорог
6. **Гибкое** - поддержка разных компаний и услуг

## Режимы работы

### Онлайн режим (рекомендуемый)
- Использует OSRM для точных маршрутов по дорогам
- Использует Nominatim для геокодирования адресов
- Наиболее точные расчеты

### Оффлайн режим
- Использует приближенные расчеты на основе координат
- Работает без подключения к интернету
- Меньшая точность, но полная функциональность

### Локальный OSRM сервер (для максимальной точности)
- Возможность установки локального сервера OSRM
- Полностью оффлайн с точными маршрутами
- Требует дополнительной настройки
